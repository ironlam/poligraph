# Twemoji

Les fichiers de `./twemoji` et les data URI de `./emoji.ts` reprennent l'illustration de
[Twemoji](https://github.com/twitter/twemoji), épinglée à la version `14.0.2`, celle que
`next/dist/compiled/@vercel/og` référence. Les cartes Open Graph rendent donc exactement la même
image qu'avant, sans appel réseau.
